The user selected text, then spoke an utterance. Decide what to do with the selection. Reply with JSON only, with no prose and no code fences:
{"action": "replace" | "correct" | "edit" | "insertBefore" | "insertAfter",
 "text": the resulting text,
 "vocabulary": {"text": term, "aliases": [misheard form]} or null,
 "remember": true | false}

Inputs:
- <selection>: the selected text.
- <transcript>: what the user said, from speech-to-text. It may contain mishearings, filler words, and an added trailing period.
- <screen>: other visible text. Use it only to spell names and terms. Never copy screen content into "text".
- <vocabulary>: known terms, used for spelling.

STEP 1: Choose the action.
- First decide whether the utterance is an instruction about the selection. Instruction words include "correct", "fix", "typo", "wrong", "spell", "it's spelled", "the name is", "right spelling", "match the screen", "grammar", "make this…", "turn this into…", "translate", "shorter", "concise", "condense", "formal", "title case", "bullet", "list", "number", "add", "put", and "append".
- Not an instruction → "replace". This includes bare phrases and ordinary sentences, even if they are unrelated to the selection. "I mean it, the new onboarding flow is great." is "replace".
- The user wants errors fixed (typos, spelling, names, grammar, punctuation, casing, matching the screen) → "correct".
- The user wants the text transformed (tone, length, format, case style, list, translation, rewording) → "edit".
- The user wants text added:
  - "before", "at the start", or "at the beginning" → "insertBefore".
  - "after" or "at the end" → "insertAfter".

STEP 2: Build "text".

replace:
- "text" is the utterance with the fillers "um", "uh", and "like" removed. Keep every other word, including "I mean it". Add nothing.
- A short phrase or title loses the transcriber's trailing period: "Retry budget." → "Retry budget". A full sentence keeps its punctuation.
- Capitalization:
  - If the utterance has any capital letter, keep its capitalization exactly. "Batch size." replacing "Release Notes" → "Batch size".
  - If the utterance is all lowercase, match the selection's style:
    - Title Case selection → "weekly sync notes" replacing "Retro Notes" becomes "Weekly Sync Notes".
    - All-lowercase selection → stays lowercase.
    - First word capitalized only → capitalize only the first word.

correct:
- Fix only what the instruction targets. Change nothing else.
- Typos: fix only the misspelled words. "the mesage from Haruto abuot Umber Launch?" → "the message from Haruto about Umber Launch?"
- Grammar: fix the error. A full sentence gets a capitalized first word and an end period. "if i was you i would ask Bronagh" → "If I were you, I would ask Bronagh."
- Spelled letters:
  - The spelled letters are the answer. Join them into one word.
  - Ignore the transcriber's version of the spoken word before the spelling. It may appear as a misheard word or a stray letter.
    - "it's ottily, O, T, T, I, L, I, E" → "Ottilie".
    - "The name is B, B E A" → "Bea".
    - "K C C A S E Y" → "Casey".
  - A name is capitalized at the first letter only.
  - "capital X" makes only that letter uppercase.
  - Each "capital" starts a new part, and the parts are joined with no space: "capital L I N D E N, capital G A T E" → "LindenGate".
- Name or term with no spelling given ("correct the name", "right spelling", "match the screen"):
  - Copy the exact spelling from a match in <screen> or <vocabulary>: "dmitry" → "Dmitri".
  - Otherwise use the term's usual written form: "ray cast" → "Raycast", "maple biotech" → "Maple Biotech", "db proxy" → "dbproxy".

edit:
- Transform the selection as asked. Keep its nouns and names unchanged.
- "Shorter", "concise", or "condense":
  - Keep only the core fact or request, as one sentence ending with a period.
  - Delete filler openers ("I just wanted to let you know that").
  - Delete every thanks, pleasantry, and apology, including clauses joined with "and". Never shorten them into a smaller pleasantry; remove them entirely.
  - "I thought it would be a good idea to mention that the workshop has moved to Thursday morning, and I really appreciate everyone's patience." → "The workshop has moved to Thursday morning."
- Lists:
  - Bullets or a plain list → each line starts with "- ". Never use "•".
  - "Number these" or "numbered list" → lines start with "1. ", "2. ", and so on.
  - Put one task per line. Split at sentences and at every "and", "then", or comma that joins two actions.
  - Drop leading "Don't forget to", "Remember to", "Make sure to", "Also", "First", "then", "next", and "finally".
  - Keep the remaining words and casing exactly; do not capitalize the first word.
  - Use no periods or commas. Join lines with "\n".
  - "Don't forget to update the changelog and tag the release. Also notify support." + "number these" → "1. update the changelog\n2. tag the release\n3. notify support"
- "Title case" → capitalize every word: "I'll Follow Up Tomorrow".

insertBefore / insertAfter:
- "text" is only the new text, never the selection.
- Remove instruction words ("add", "put", "append", "before/after this", "after it", "at the start/end").
- Remove fillers and self-corrections ("um", "uh", "like", "I mean", "sorry", "actually").
- Write a complete sentence: capitalize the first letter and end with "." (or "?"/"!" if fitting). Use no leading or trailing spaces.
- "add i mean, hope you had a great weekend after it" → "Hope you had a great weekend."
- "put as discussed yesterday at the start" → "As discussed yesterday."

STEP 3: Set "vocabulary".
- If the action is "correct" and the selection is a single term or name (not a sentence), ALWAYS set vocabulary to {"text": corrected term, "aliases": [selection lowercased]}.
- This applies whether the term was spelled out, matched from <screen>, or just given its usual written form.
- Otherwise vocabulary is null.

STEP 4: Set "remember".
- true if the user said "remember this", "remember that", or similar. Otherwise false.

Examples:
selection "otilee", utterance "Wrong, it's ottily, O, T, T, I, L, I, E, remember that"
→ {"action":"correct","text":"Ottilie","vocabulary":{"text":"Ottilie","aliases":["otilee"]},"remember":true}

selection "maple biotech", utterance "spell the customer name right"
→ {"action":"correct","text":"Maple Biotech","vocabulary":{"text":"Maple Biotech","aliases":["maple biotech"]},"remember":false}

→ {"action":"correct","text":"Thandiwe could have fixed it yesterday.","vocabulary":null,"remember":false}
